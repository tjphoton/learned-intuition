Recognize · SBI

Simformer: All-in-One SBI

Gloeckler, Deistler, Weilbach, Wood, Macke·2024
Open PDF (private repo) Back to study plan
Summary

Transformer-based SBI that handles missing data and flexible conditioning via masking — condition on any subset of parameters or data at inference time. Real commercial panels are rarely complete; this is that exercise.

Study Notes

The core move: one network for every conditional, not one fixed target

Every SBI method so far in this library picks one fixed target: NPE learns p(θ|x), NLE learns p(x|θ), NRE learns a ratio. Simformer instead trains a single probabilistic diffusion model on the full joint p(θ,x), such that any conditional of that joint — the posterior, the likelihood, or an arbitrary conditional like p(θ₁,θ₂|x₁) or p(x₂|θ₁,x₁) — can be sampled from the same trained network afterward. This directly generalizes JANA (which jointly amortizes exactly two targets, posterior and likelihood) to every conditional at once.

How: tokenize everything, randomly mask during training

Every variable — each parameter, each data point — becomes a token carrying an identifier, its value, and a binary condition-state (observed/conditioned vs. latent/to-be-inferred). During training, this condition-state is resampled at every iteration: sometimes the mask corresponds to the posterior task, sometimes the likelihood task, sometimes two randomly sampled subsets. Training on many different random splits is exactly what makes sampling from arbitrary conditionals possible at inference time — the network never specializes to one fixed input/output split.

The score-based diffusion machinery

A denoising score-matching objective trains a transformer to predict the score (gradient of the log-density) of the (partially) noised joint at each diffusion timestep; sampling runs the corresponding reverse-time SDE. Because the target output is a score, not a fixed-size vector, the same trained model naturally accommodates variable numbers of tokens — which is exactly what makes irregular/unstructured/missing/function-valued data tractable, discussed below.

Attention masks encode domain knowledge directly — Cranmer's "open the black box" idea, implemented

When the simulator's true conditional-dependency structure is known (e.g. a Markov chain, where each state genuinely only depends on the previous one), that structure can be encoded directly as the transformer's attention mask — a concrete, six-years-later implementation of the "stop treating the simulator as a black box" theme from Cranmer et al. The paper backs this with real graph theory (Appendix A1): it proves precisely which conditional-independence guarantees an attention mask can and cannot enforce, and at what diffusion noise levels — a genuinely rigorous treatment, not just "add domain knowledge and hope."

Capabilities with no analog in NPE/NLE/NRE

  • Function-valued (infinite-dimensional) parameters — e.g. a time-varying contact rate in an epidemiological model, not just a fixed-size parameter vector. Handled via subsampling random points from the underlying continuous index set during training (justified via the Kolmogorov Extension Theorem), rather than a fixed discretization grid.
  • Unstructured, irregularly-sampled data — e.g. predator and prey population counts measured at different, non-aligned time points in a Lotka-Volterra ecological model. No summary statistics needed; inference runs directly on the raw irregular series.
  • Missing data — handled by the same tokenization scheme natively, with no special-casing required.
  • Guided diffusion for interval/constraint conditioning — condition not just on exact observed values but on an interval or arbitrary constraint (demonstrated by finding energy-efficient parameter configurations in a Hodgkin-Huxley neuron model — "keep metabolic cost below a threshold" — while remaining consistent with observed voltage traces). Genuinely new relative to standard NPE/NLE/NRE, which condition on point observations only.

Benchmark results, with real numbers

Across all four standard benchmark tasks (Gaussian Linear, Gaussian Mixture, Two Moons, SLCP), Simformer outperformed NPE on posterior accuracy (C2ST) — even using a dense, uninformed attention mask — with one exception (the Gaussian Linear task specifically at 10,000 simulations). Encoding known dependency structure into the attention mask improved accuracy further, especially on tasks with sparser true structure. Averaged across all tasks, Simformer needed about 10× fewer simulations than NPE to reach comparable accuracy — a genuine sample-efficiency win, not merely a flexibility one. On the SIRD epidemiological case study, the inferred posterior for the time-varying contact rate sensibly widens exactly during periods when infections approach zero — there's genuinely nothing in the data at that point to inform the estimate, and the model correctly says so instead of overclaiming confidence.

Honest, stated limitations

  • Slower sampling than NPE — normalizing flows (NPE's usual backbone) sample in one shot; Simformer must solve a reverse SDE, though as few as ~50 steps sufficed for accurate results in their experiments (a few seconds for 10,000 samples — still far faster than MCMC).
  • Quadratic scaling with token count — transformer attention cost grows quadratically with the number of parameters/data points, a real constraint for very high-dimensional problems, partially mitigated by sparse attention when independence structure is known.
  • Estimating all conditionals ≈ estimating the joint — in problems with few parameters but very high-dimensional data (images, long time series), learning the full joint may genuinely be harder than targeting the posterior alone would be. (Simformer can still be queried for just the one conditional actually needed, rather than always computing everything.)
  • Log-probability evaluation is more expensive than for normalizing-flow-based NPE/NLE — it requires solving the probability-flow ODE. Point estimation (MAP) and MCMC integration remain practical, though, since the score function itself supports gradient ascent and Langevin-MCMC directly, without needing a full log-probability evaluation.

Explicit positioning: five prior papers, each solving one piece, generalized here

The paper's own related-work section is unusually direct about what's genuinely new: prior work separately handled function-valued parameters (but only with fixed discretizations), irregularly-sampled time series (but via ABC, not amortized), missing data (via data augmentation and RNNs), and joint posterior+likelihood estimation (JANA and Glöckler et al. 2022 — but as two separate learned networks, not one). Simformer's contribution is explicitly framed as unifying all of these into one architecture rather than introducing any single one of them for the first time.

Discussion, Section by Section

Plain-English walkthrough (start here)

Builds on cranmer.html's three-way split (posterior/likelihood/ratio) and the "mining gold"/opening-the-black-box theme from that same paper — Simformer is best understood as what happens when you take that six-year-old idea and rebuild it with modern diffusion models and transformers.

1. Why pick one target when you can train on everything at once?

Every earlier method in this library commits early: "I will learn the posterior" or "I will learn the likelihood." That's a real cost if your questions change later — say you first want "given this data, what are the parameters," then later want "given these parameters and part of the data, what's the rest of the data." Normally that means training two separate networks. Simformer's trick is to randomly hide different pieces of information during training, over and over, so the network never specializes to one fixed question — it learns to answer any fill-in-the-blank question about the whole system, and you pick which blanks to fill in after the fact.

2. Handling "I don't have a clean, complete spreadsheet"

A lot of earlier methods quietly assume your data always arrives in the same tidy shape — same number of measurements, same timing, nothing missing. Real ecological or medical data rarely cooperates: predator counts and prey counts get measured on different days, some sensors fail, some measurements are just never taken. Because Simformer treats each individual data point as its own token rather than forcing everything into one fixed-size vector, gaps and irregular timing aren't special cases needing extra machinery — they're just tokens that happen to be missing from a given input.

3. "Find me a good answer within these limits," not just "match this exact number"

Normally, conditioning means "given exactly this observed value, what follows?" Guided diffusion adds a genuinely new kind of question: "given that I need the answer to satisfy some constraint — like keeping energy use under a threshold — steer me toward configurations that do." That's closer to how an engineer actually poses a design question (find settings that work and are efficient) than how a scientist poses a pure inference question (given this data, what's the parameter) — a real expansion of what "conditioning" can mean.

4. A correctly humble model, not just an accurate one

The SIRD epidemic example is worth remembering as a small but important sanity check: when there's essentially no disease spreading, there's genuinely very little information in the data about how contagious the disease currently is, and a trustworthy model should say "I'm not sure" rather than confidently guessing. Simformer's uncertainty widens exactly there — a concrete, visible instance of well-calibrated behavior, not just a claim about it.
